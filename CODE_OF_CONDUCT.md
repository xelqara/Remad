# Code of Conduct

Remad is intended to support rigorous, respectful, and responsible technology work. Participants must communicate professionally, credit original work, protect confidential information, and avoid harassment, discrimination, deception, or misuse of data.

Disagreements should focus on evidence, assumptions, implementation, and outcomes. Maintainers may pause or reject contributions that create legal, security, privacy, or conduct risk.

This code is a project policy draft and does not create an employment, partnership, or agency relationship.
