# Dependency and Provenance Register

Every external dependency used by Remad must be recorded before release.

| Item | Version | Source | License | Intended use | Review status |
|---|---|---|---|---|---|
| None registered | — | — | — | No external runtime dependency declared in this foundation document. | Pending future implementation |

When a dependency is added, record its exact version, source URL, license identifier, copyright notices, security status, and whether its terms permit the intended commercial use. Models, datasets, fonts, icons, generated media, and API services must be treated as dependencies when their terms affect use or distribution.

A dependency record is evidence of review, not a replacement for compliance with the underlying license.
