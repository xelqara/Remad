# Contributing to Remad

Remad is proprietary by default. Contributions are considered only when Xelqara AI has approved the proposal in writing.

Before submitting work, contributors must disclose authorship, source material, dependencies, data provenance, model provenance, and any restrictions. Do not submit material copied from a private employer, client, university, or third party without permission.

A contribution may require a signed agreement that defines confidentiality, copyright, invention rights, moral rights where applicable, and the permission granted to Xelqara AI. Approval of a pull request does not by itself prove that an ownership transfer occurred.

All contributions should be small, reviewable, tested where applicable, documented, and accompanied by a statement of limitations. Security or privacy concerns should be reported privately according to `SECURITY.md`.

This file is a project policy draft and not formal legal advice.
